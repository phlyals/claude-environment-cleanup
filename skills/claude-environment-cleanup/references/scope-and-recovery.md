# 范围、注入来源与恢复

## 预览与预检

默认预览没有写入、不会调用 Claude 或读取钥匙串中的密码；它仍可能读取包含敏感值的本地 JSON 以解析结构，只输出键名而不输出值。不要把配置全文、数据库行、shell 环境值粘贴到聊天、日志或 GitHub。

自动脚本只支持默认配置目录和当前用户。`CLAUDE_CONFIG_DIR` / `XDG_CONFIG_HOME` 非空、清理路径带符号链接、JSON 格式异常、Claude 仍运行时停止。不要仅取消环境变量就假装自定义配置已清理。

在 Agent 预检中按实际使用位置检查：

- 用户 `settings.json` / `settings.local.json` 的 `env`、`apiKeyHelper`。
- 用户明确相关的项目 `.claude/settings.json`、`.claude/settings.local.json`、启动参数及 IDE 设置。不要遍历、修改所有项目。
- 当前进程与新登录 shell 的认证变量；shell 文件可能间接 source 其他文件，脚本的静态扫描不是完整解释器。检查 `ANTHROPIC_API_KEY`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_BASE_URL`、`CLAUDE_CODE_OAUTH_TOKEN`、第三方云认证开关及文件描述符凭据来源，输出名称即可。
- macOS launchd 注入、已配置的托管设置和环境策略；组织管理的设置不能擅自改动。
- 已安装的 CC Switch 或类似工具是否正在注入 Claude 的代理/API 配置。只看 Claude 对应部分，保留其他产品与账户；如仍注入，先在授权范围暂停对应接管或准确修正来源。

发现 API key / 自定义 BASE_URL 时先说明它是仍在使用还是要清除的残留。用户要求保留现有线路时，不把自定义 API 网关与系统网络线路混为一谈。选择不明确且会影响现有服务，停在该项询问；其余只读核对可以继续。

若已授权清除这些具体残留，**在任何编辑之前**，用 700 权限的私有目录完整备份 `.claude`、`.claude.json` 和涉及的额外配置，核对文件哈希。仅删确认的键/行，保留其他 env、权限、model、MCP、手工配置。JSON 解析失败直接停止。完成后重跑脚本预览；不要为“通过预检”清空整个 `env` 或绕过检查。

## 自动脚本的真实边界

执行时的持久化位置是 `~/.claude-cleanup-backups/<UTC时间>-<随机后缀>/`，不在仓库或活动 Claude 配置目录中。目录仅当前用户可访问。这里包括：

- `backup/dot-claude/`：退出登录前完整副本，保留符号链接本身，不跟随链接拷贝外部目录。
- `backup/claude.json`：退出登录前身份配置。
- `backup/identity-before-reset.json`：重置时原子移出的准确版本，保留临界时刻的写入。
- `manifest-before.json`、`external-before.json`、`preview.json`：私有基线。
- `quarantine/` 与 `quarantined.json`：移出的缓存及旧恢复副本。
- `result.json`：成功后生成；`failure.json`：失败阶段，不包含原始命令输出。

备份可能包含登录信息或个人历史。**不上传备份、执行记录、截图或真实配置；分享时仅分享 Skill 源码。** 没有自动清除备份的计时器。

脚本用文件锁串行化自身实例，以不跟随符号链接的目录句柄移动缓存；身份文件先移出保留，再以不覆盖现有文件的方式提交。第三方程序不遵守本脚本的锁，仍须先停止相关写入者。发现竞争时停止并保留各版本；任何时点验收都不能保证随后没有程序重新写回。

脚本会保留未知配置字段，只清理源码中显式列出的账号缓存和重置项。现有保护项变化即失败，不能把报错降级成成功。CLI 自身可能创建日志等新文件；日志新增不等于用户数据丢失。原生 CLI 的新版本可能生成新的匿名 userID 或迁移 `numStartups`，需要根据当次状态解释。

脚本核对旧有 `.claude` 保留项和一组常见外部配置；它没有扫描或保证整台电脑的所有文件。网络软件不会被调用或修改。脚本不自动停止进程、清理浏览器、修改切换器、安装 CLI 或发起模型请求。

## 失败与恢复

1. 失败时停止并保留整份私有运行目录。读 `failure.json` 的阶段；成功退出登录后发生的失败仍可能已退出登录或部分移走缓存，不能宣称“完全没改”。
2. 先检查准确的 `quarantined.json` 与备份哈希，确认当前 Claude 进程已关闭。目标文件已经存在时先比较，不覆盖新数据。
3. 只在用户明确要求恢复时恢复必要的非认证文件。恢复 `backup/claude.json`、凭据文件或旧恢复副本可能恢复旧账号状态；不要自动回滚它们。
4. 系统钥匙串不在文件备份中；官方退出操作不能靠复制目录保证撤销。恢复登录由用户正常登录完成。
5. 用户要求永久删除旧备份属于单独范围，不能由清理 Skill 默默扩大执行。

## 网络与安装

保留现有代理/节点/DNS/时区是默认边界。需要检测时分别报告实际出口、DNS/WebRTC 结果和未测项目，不用静态配置或第三方评分代替真实连接证据。默认不做 IP 信誉查询，也不将真实 IP 上传第三方。

仅在安装有问题或用户明确要求时独立检查安装，并使用当前官方安装说明。安装更新、启动、登录都会改变运行状态，不能和“清理后保持关闭未登录”的验收混在一起。
